# 点対称連結ポリオミノ同士の引き算

[ツールを開く](https://tatt61880.github.io/symmetry-mino-subtraction/)

濃い点線の枠内にピンクの図形Aを描くと、水色の図形Bを足して、Bと全体（A＋B）がともに点対称で連結になる中心点を探します。すでにAだけで点対称かつ連結なら、その中心には十字が付きます。

- 指やマウスでなぞってマスを塗ります。塗ったマスからなぞると消せます。
- マウスを中心点に近づけると、水色の解が表示されます。「解の確認」に切り替えると、タップでも好きな中心を選べます。数字付きの点は、繰り返し押すと別の解に切り替わります。
- 「現在の盤面のURL」で図形Aを共有できます。「手動モード」では、Aを固定したまま自分でBを描けます。

## 探索手順

全体の中心を濃い点線の枠内に仮定し、Aをその点で反転させます。Aからはみ出したマスは、必ずBの一部です。

点対称な図形の重心は対称中心に一致します。そこで、追加するマス数を仮定し、Aの重心と全体の中心からBの中心候補を求めます。全体とB、それぞれの中心で交互に反転して必要なマスを埋め、盤面内で対称性と連結性を確かめます。

Aが仮定した中心に対してすでに点対称でも、離れた部分がある場合は、それらをつなぐ点対称なBを探します。同じ中心で複数の補い方がある場合、このケースでは一例を表示します。
